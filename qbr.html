5 missing APIs that matter most
1
Holiday schedule
Most-requested bulk action. Currently internal-only — no public endpoint exists.
2
CC-level recording policy
Compliance teams need "always record" at the CC level. User-level toggle exists; CC policy does not.
3
AI / voice intelligence fields
Object exists in the API but sub-fields are undocumented. Lowest-effort fix — just needs schema exposure.
4
CSAT survey config
Zero public API coverage. Enterprises need consistent CSAT settings across all CCs.
5
Batch / async update endpoint
Without this, applying a change to 200 CCs requires 200 sequential API calls. Required for the agent to operate reliably at scale.
