Section 1
The template model
A template is a named configuration profile. Settings are either 🔒 Locked (CCs can't change it) or ✎ Adjustable (template sets the default, CC can override).

Section 4 · Dependency
Align with new Global Admin IA
Core UX is redesigning Admin with global search, URL-addressable settings, and a structured information architecture. The Admin Agent should live inside this new experience — and eventually consume the same navigation registry.
What Core UX is building
→
Global search — admin searches "Call Center Routing" and navigates directly to that setting
→
URL-addressable settings — every setting has a stable, shareable URL
→
Navigation metadata model — settings discoverable from a central registry
→
Structured information architecture — consistent, predictable settings hierarchy
The Admin Agent should live inside this new Global Admin experience — not as a side panel on top of the old UI.
How AI leverages the same registry
Once the navigation schema is available, the Agent can consume it directly instead of maintaining manual setting mappings.
Agent knows where settings live — navigates automatically without hardcoded paths
Better discoverability — agent surfaces settings the admin didn't know existed
Easier bulk execution — same metadata model drives both UI navigation and agent actions
Open question: When will Core UX expose the navigation schema? This determines Phase 2 start date.

What needs alignment

5 open questions

Core UX navigation schema — what metadata/schema will Core UX expose for settings navigation? Can the Admin Agent leverage the same registry? When is it available?
2
API gap ownership — who owns the 5 new public API endpoints (holiday schedule, CC recording policy, AI/voice intelligence fields, CSAT, batch)? Platform team, CC backend, or dedicated API team? This determines Q4 start date.

First end-to-end agent workflow — what is the first agentic workflow to prototype for Phase 2? Suggested: "Apply EMEA compliance settings to all European CCs" as the proof-of-concept.
4
Template versioning & inheritance — how should template versioning work? How are templates applied during new CC creation vs. existing CCs?

Global Admin IA timeline — when does the new Global Admin experience launch? The Admin Agent UI positioning depends on this. Phase 2 should launch inside the new IA, not the old one.
